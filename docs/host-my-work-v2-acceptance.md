# Host My Work V2 acceptance checks

- Open, Blocked, and Critical controls filter the task list and show an active state.
- Main screen shows active event cards with remaining task counts and progress.
- Work area tiles show aggregate open-task counts across events.
- Tapping a work area opens a dedicated screen rather than expanding My Work inline.
- Work area screen lists open tasks across all events and supports event filtering.
- Event picker changes which event receives a task pack.
- Pack assessment runs again when the selected event changes.
- Completed matching tasks appear as Complete and are not selected.
- Existing incomplete matching tasks appear as Already in My Work and are not selected.
- Supported event-component completion signals can mark pack items complete without a matching task.
- Missing items are selected by default and can be individually deselected.
- Add Missing Tasks inserts only selected missing items.
- Stable pack task keys prevent duplicate pack-task insertion.
- Quick Add remains visible as a floating input and can add a task without opening a separate form.
- Import is removed from the primary action row and placed in the secondary My Work menu.
